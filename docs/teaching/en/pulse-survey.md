# Pulse survey (anonymous, two minutes)

Hand out at the end of a lecture, after the exit ticket, on paper or with an anonymous online form that does not
collect names, e-mail addresses or student numbers. Answer each statement from **1** (strongly disagree) to **5**
(strongly agree).

| # | Statement | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | At the start of the lecture I knew what I was expected to be able to do by the end. | | | | | |
| 2 | I had the knowledge needed to follow this lecture (from earlier lectures or from *Starting from Zero*). | | | | | |
| 3 | I understood how today's topic connects to what we did before and to what comes next. | | | | | |
| 4 | I could explain today's key concept to a classmate who missed the lecture. | | | | | |

Optional: **What was the least clear moment of today's lecture?** ______________________________________________

Lecture: ____   Date: ____________

*For the instructor:* record only the counts of each answer per question (see `pilot-protocol.md`). Do not try to
identify students; do not link the survey to the exit tickets.
