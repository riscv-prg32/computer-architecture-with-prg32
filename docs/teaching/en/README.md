# Teaching instruments (English)

Material for the instructor and the students of ARC12, beside the decks, the notes and the textbook. The Italian
version is in [`../it`](../it/README.md); the two are kept in step.

| File | For | What it is |
| --- | --- | --- |
| [learning-status-guide.md](learning-status-guide.md) | instructor, to read aloud | UNDERSTAND NOW, USE NOW, UNDERSTAND LATER: what they mean and what to say |
| [facilitation-template.md](facilitation-template.md) | instructor | a 60-90 minute lecture plan: orientation, demo, prediction, explanation, practice, retrieval, closing |
| [lesson02-facilitation.md](lesson02-facilitation.md) | instructor | the plan of Lecture 02, minute by minute, with the pauses, the misconceptions and the recovery paths |
| [verm1-milestones.md](verm1-milestones.md) | instructor and students | the four parts of Verm1: prerequisites, checkpoints, common mistakes, rescue path, exit check |
| [exit-tickets.md](exit-tickets.md) | students | the exit ticket of each lecture (generated, no answers) |
| [rubrics.md](rubrics.md) | instructor | every assessment item with concepts, rubric and misconception (generated; not for projection) |
| [roadmaps.md](roadmaps.md) | both | outcomes, prerequisites, bridges and closing of each lecture (generated) |
| [pulse-survey.md](pulse-survey.md) | students | a four-question anonymous survey, 1 to 5 |
| [pilot-protocol.md](pilot-protocol.md) | instructor | how to measure Lectures 02-05 in class, and how to decide what to change |

The generated files come from `tools/concepts/assessments.json`, `bridges.json` and the registry:
`cd tools && npm run teaching`. Change the sources, never the generated files.

**What is not known.** These instruments have been written and checked for consistency with the course; they have not
yet been used in a classroom. Whether they improve learning is **not verified**: it requires the data that the pilot
protocol describes.
