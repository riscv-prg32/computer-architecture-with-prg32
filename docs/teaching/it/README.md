# Strumenti didattici (italiano)

Materiale per il docente e per gli studenti di ARC12, accanto alle presentazioni, alle note e al libro. La versione
inglese è in [`../en`](../en/README.md); le due sono tenute allineate.

| File | Per | Che cos'è |
| --- | --- | --- |
| [learning-status-guide.md](learning-status-guide.md) | docente, da leggere ad alta voce | DA COMPRENDERE OGGI, DA UTILIZZARE OGGI, DA COMPRENDERE PIÙ AVANTI: che cosa significano e che cosa dire |
| [facilitation-template.md](facilitation-template.md) | docente | lo schema di una lezione di 60-90 minuti: orientamento, dimostrazione, previsione, spiegazione, pratica, richiamo, chiusura |
| [lesson02-facilitation.md](lesson02-facilitation.md) | docente | il piano della Lezione 02, minuto per minuto, con le pause, gli errori tipici e come recuperare |
| [verm1-milestones.md](verm1-milestones.md) | docente e studenti | le quattro parti di Verm1: prerequisiti, punti di controllo, errori comuni, percorso di recupero, verifica finale |
| [exit-tickets.md](exit-tickets.md) | studenti | il biglietto d'uscita di ogni lezione (generato, senza risposte) |
| [rubrics.md](rubrics.md) | docente | ogni prova con concetti, griglia ed errore tipico (generato; da non proiettare) |
| [roadmaps.md](roadmaps.md) | entrambi | risultati, prerequisiti, ponti e chiusura di ogni lezione (generato) |
| [pulse-survey.md](pulse-survey.md) | studenti | un questionario anonimo di quattro domande, da 1 a 5 |
| [pilot-protocol.md](pilot-protocol.md) | docente | come misurare in aula le Lezioni 02-05, e come decidere che cosa cambiare |

I file generati vengono da `tools/concepts/assessments.json`, `bridges.json` e dal registro:
`cd tools && npm run teaching`. Si modificano le sorgenti, mai i file generati.

**Che cosa non si sa.** Questi strumenti sono stati scritti e verificati per coerenza con il corso; non sono ancora
stati usati in aula. Se migliorino l'apprendimento **non è verificato**: richiede i dati descritti nel protocollo pilota.
