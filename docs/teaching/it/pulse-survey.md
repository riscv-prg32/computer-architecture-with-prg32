# Questionario lampo (anonimo, due minuti)

Da distribuire alla fine di una lezione, dopo il biglietto d'uscita, su carta o con un modulo online anonimo che non
raccolga nomi, indirizzi e-mail o numeri di matricola. Rispondete a ogni affermazione da **1** (per niente d'accordo) a
**5** (del tutto d'accordo).

| # | Affermazione | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | All'inizio della lezione sapevo che cosa avrei dovuto saper fare alla fine. | | | | | |
| 2 | Avevo le conoscenze necessarie per seguire questa lezione (dalle lezioni precedenti o da *Partire da zero*). | | | | | |
| 3 | Ho capito come l'argomento di oggi si collega a ciò che abbiamo fatto prima e a ciò che viene dopo. | | | | | |
| 4 | Saprei spiegare il concetto chiave di oggi a un compagno che ha perso la lezione. | | | | | |

Facoltativo: **Qual è stato il momento meno chiaro della lezione di oggi?** ______________________________________________

Lezione: ____   Data: ____________

*Per il docente:* registrare solo i conteggi di ogni risposta per domanda (vedi `pilot-protocol.md`). Non cercare di
identificare gli studenti; non collegare il questionario ai biglietti d'uscita.
